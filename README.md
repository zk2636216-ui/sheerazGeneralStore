# Sheeraz General Store (Khattak) — Online Grocery & Essentials

A modern, responsive, mobile-first web application for **Sheeraz General Store**, owned by **Fahad Islam** and **Sadam Hussain** in **Khattak, Khyber Pakhtunkhwa**.

Engineered by **Zakriya Khan — Full Stack Engineer**.

---

## 🚀 Features

- **Store Aisles & Categories**:
  - Pepsi & Drinks
  - Ice Creams
  - Masala & Spices
  - Chips & Snacks
  - Beans, Rice & Grains
  - Electrical Items
  - Mobile Top-Ups & Easypaisa (with interactive instant top-up counter)
  - Household Essentials
- **Live Search & Instant Filtering**: Search by item name, brand, or ingredients with live suggestions.
- **Cart & Quick-View Modal**: Easy quantity adjustments, instant subtotals, item removal, and full product preview.
- **Customizable Store Settings**: Interactive settings panel to edit announcement strip, phone, address, operating hours, Easypaisa account, and bank IBAN in real time.
- **Checkout & Multi-Payment**:
  - Cash on Delivery (COD)
  - Easypaisa Mobile Wallet
  - Direct Bank Transfer (IBFT)
  - Clear payment verification notices & print-ready invoice.
- **Mobile First Design**: Dedicated bottom navigation bar for small screens, responsive touch targets, and fluid layout across all devices.
- **GitHub Pages Ready**: Configured with relative base path (`base: './'`) and `public/404.html` SPA fallback.

---

## 🛠️ Tech Stack

- **Framework**: React 19 (TypeScript)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite (`base: './'`)

---

## 📦 Deploying to GitHub Pages

1. **Build the static site**:
   ```bash
   npm run build
   ```
2. The production bundle is generated in the `dist/` directory.
3. Push to your GitHub repository and enable **GitHub Pages**:
   - Go to **Settings** > **Pages**
   - Source: Deploy from branch `gh-pages` or use GitHub Actions (`Actions` tab).
